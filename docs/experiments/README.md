## 실행

실험은 몇 분씩 걸려 기본 빌드(`./gradlew build`)에서 돌지 않습니다. 따로 돌립니다.

```bash
./gradlew :inventory-service:experiment     # 01
./gradlew :messaging:experiment             # 02
./gradlew :system-experiment:experiment     # 03. 네 서비스를 실행 jar 로 띄운다
./gradlew :fulfillment-batch:experiment     # 04
```

결과는 각 모듈의 `build/experiment-results/` 에 표로 남습니다. 이 문서들의 숫자는 거기서 옮겼습니다.

## 숫자를 읽을 때

모든 측정은 Apple M3 8코어 노트북의 Docker Desktop 위에서 했습니다. MySQL 과 Kafka 가 컨테이너 하나씩입니다.
노트북의 디스크 동기화는 운영 DB 보다 훨씬 빨라, 커밋 시간에 묶인 숫자(행 잠금 처리량, 릴레이 기록)는 낙관적입니다.
그래서 절대값보다 방식 사이의 차이와, 무엇이 병목인지를 봅니다.
