## 읽는 법

- **참여자:** 서비스 이름(주문, 재고, 결제, 풀필먼트)은 그 서비스의 API 나 소비자입니다. "주문 DB" 처럼 DB 를 따로 그린 것은 그 서비스 안에서 일어나는 갱신을 드러내려는 것입니다
- **한 트랜잭션:** 메시지 끝의 "(한 트랜잭션)"은 그 안의 변경이 함께 커밋된다는 뜻입니다
- **조건부 갱신:** "A 를 B 로"는 `WHERE status = 'A'` 를 건 갱신입니다. 0행이면 이미 다른 경로가 바꾼 것입니다
